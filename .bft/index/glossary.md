# Glossary — Глоссарий

## Термины контура производства

| Термин | Определение | Источник |
|---|---|---|
| **БФТ** | Бизнес-функциональные требования — документ, описывающий требования к эпику или фиче в корпоративном формате. | po-statement.md:3 |
| **HowToDemo** | Конкретный сценарий проверки готовности: что запустить, что сделать, что должно получиться. Граница MVP. | CLAUDE.md:9-10 |
| **Issue-Agent** | Агент, проводящий триаж Issue: выставляет метки advisor:*, priority:*, phase:classified. | README.md:9-10 |
| **OpenHands** | Агент разработки, работающий headless на раннере GitHub Actions. | DEMO.md:30 |
| **PR-Agent** | Агент ревью, проверяющий PR и оставляющий комментарий с verdict. | README.md:51-52 |
| **SubIssue** | Подзадача, созданная для edge-кейса с меткой `origin:agent` и ключом `root-issue: #N`. | CLAUDE.md:15-18 |
| **FNR** | Functional Requirements — цепочка навыков: task → concept → debate → sysreq → validate. | DEMO.md:57-60 |
| **ready-for-dev** | Метка и чеклист готовности — точка передачи от Research к Develop. | DEMO.md:35-37 |
| **entire** | Память прогонов контура — сессии и чекпоинты агента, лежащие в git-рефах репозитория. | po-statement.md:28-30 |
| **ruflo** | Координатор опциональный для BFT-обогатителя. Без него деградация на нативные Claude-субагенты. | bft-deep skill description |
| **канон** | Каноническая структура БФТ ниже строки-границы, наращиваемая по 3 осям (ценность/what-if/границы). | bft-deep skill description |
