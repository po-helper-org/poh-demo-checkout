# FNR-1: Параметризация порога бесплатной доставки

## Статус
**Состояние:** Исследование выполнено, awaiting concept

## Резюме

Требуется вынести жёстко заданные константы стоимости доставки (`DELIVERY_FEE = 300`, `FREE_DELIVERY_FROM = 3000`) в конфигурацию и добавить расчёт остатка до бесплатной доставки для отображения на витрине корзины.

## Диагноз проблемы

### Текущее состояние (AS IS)

**Расчёт доставки локализован в одном месте:**

- **Файл:** `src/pricing.mjs:40-42`
- **Функция:** `deliveryFee(amount)`
- **Логика:**
  ```javascript
  export function deliveryFee(amount) {
    return amount >= FREE_DELIVERY_FROM ? 0 : DELIVERY_FEE;
  }
  ```
- **Константы:**
  - `DELIVERY_FEE = 300` — стоимость платной доставки (строка 5)
  - `FREE_DELIVERY_FROM = 3000` — порог бесплатной доставки (строка 10)

**Семантика порога:** включительно. Комментарий в коде (`pricing.mjs:7-9`) явно указывает: *"«от 3000» в тексте оферты означает включительно"*. Это юридически значимо для оферты.

**Зависимости (impact surface):**
1. `src/server.mjs` — импортирует `quote` из `pricing.mjs`
2. `tests/pricing.test.mjs` — прямые тесты всех функций

**Всего 2 зависимых файла.** Никаких других компонентов расчёт доставки не затрагивает.

**История изменений:**
- Файл создан **2 дня назад** (2026-08-17) единственным коммитом `"feat: демо-стенд контура производства"`
- Автор: `kibarik`
- Архитектурных решений, управляющих этим файлом, нет
- История изменений минимальна

**Конфигурация:**
- Централизованного механизма конфигурации **нет**
- Паттерн параметризации через `process.env` уже используется в `server.mjs:8` для порта:
  ```javascript
  const PORT = Number(process.env.PORT || 8080);
  ```
- Это естественный способ параметризовать пороги доставки

**Тестовое покрытие:**
- `tests/pricing.test.mjs` покрывает всю логику доставки:
  - Платная доставка ниже порога (строка 29-31)
  - Бесплатная доставка на пороге, включительно (строка 33-36)
  - Итоговый расчёт с доставкой (строка 38-52)

## Доказательства кода

**Константы доставки:**
```javascript
// src/pricing.mjs:5
export const DELIVERY_FEE = 300;

// src/pricing.mjs:10
export const FREE_DELIVERY_FROM = 3000;
```

**Функция расчёта доставки:**
```javascript
// src/pricing.mjs:40-42
export function deliveryFee(amount) {
  return amount >= FREE_DELIVERY_FROM ? 0 : DELIVERY_FEE;
}
```

**Использование в quote:**
```javascript
// src/pricing.mjs:48-52
export function quote(items) {
  const goods = subtotal(items);
  const delivery = deliveryFee(goods);
  return { goods, delivery, total: goods + delivery };
}
```

**Паттерн конфигурации в server.mjs:**
```javascript
// src/server.mjs:8
const PORT = Number(process.env.PORT || 8080);
```

**Семантика порога (комментарий):**
```javascript
// src/pricing.mjs:7-9
// Порог бесплатной доставки. Заказ ровно на пороге доставку уже не платит:
// «от 3000» в тексте оферты означает включительно, и расхождение здесь стоило
// бы дороже, чем читается.
```

**Тесты доставки:**
```javascript
// tests/pricing.test.mjs:29-31
test('доставка платная ниже порога', () => {
  assert.equal(deliveryFee(FREE_DELIVERY_FROM - 1), DELIVERY_FEE);
});

// tests/pricing.test.mjs:33-36
test('на пороге доставка уже бесплатна', () => {
  // «от 3000» в оферте означает включительно.
  assert.equal(deliveryFee(FREE_DELIVERY_FROM), 0);
});
```
