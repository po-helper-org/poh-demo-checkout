# FNR-1: Пересчет цены в международную валюту

## Метаданные

- **Тип задачи:** Новая функциональность (feature)
- **Критичность:** P3
- **Источник:** Issue #11
- **Дата анализа:** 2026-08-19

## Описание проблемы

**Что нужно:**
Показывать цену одновременно в базовой валюте (рубли) и её пересчёт в USD, KZT, CNY при демонстрации клиенту.

**Что есть сейчас:**
Система работает только с одной валютой — рублями. Все расчёты (`src/pricing.mjs`) возвращают суммы в рублях без возможности конвертации.

**Ограничение:**
Отсутствует функционал мультивалютности и конвертации денежных сумм.

## Анализ кодовой базы

### Текущее поведение

**Файл: `src/pricing.mjs`**

```javascript
export const DELIVERY_FEE = 300;        // Фиксированная плата за доставку в рублях
export const FREE_DELIVERY_FROM = 3000; // Порог бесплатной доставки в рублях

export function subtotal(items) {
  // Расчёт суммы позиций в рублях
  return items.reduce((sum, item) => sum + item.price * item.qty, 0);
}

export function deliveryFee(amount) {
  return amount >= FREE_DELIVERY_FROM ? 0 : DELIVERY_FEE;
}

export function quote(items) {
  const goods = subtotal(items);
  const delivery = deliveryFee(goods);
  return { goods, delivery, total: goods + delivery }; // Все суммы в рублях
}
```

**Файл: `src/server.mjs`**

```javascript
export const app = async (req, res) => {
  if (req.url === '/quote' && req.method === 'POST') {
    return send(res, 200, quote(body?.items)); // Возвращает только рубли
  }
}
```

**Файл: `tests/pricing.test.mjs`**

Все тесты проверяют расчёты только в рублях:
```javascript
assert.equal(subtotal([{ sku: 'a', price: 500, qty: 3 }]), 1500); // Только рубли
```

### Диагноз

1. **Нет курсов валют:** Система не хранит и не использует курсы конвертации.
2. **Нет типа валюты:** Структуры данных не содержат поле для указания валюты.
3. **Нет функции конвертации:** Отсутствует логика пересчёта сумм.
4. **API возвращает одну валюту:** Эндпоинт `/quote` не поддерживает запрос мультивалютного ответа.
5. **Нет тестов для конвертации:** Покрытие тестами ограничено одно-валютными расчётами.

## Открытые вопросы

2. **Обратная совместимость:**

3. **Формат ответа:**
   - Массив валют?
   - Объект с полями `RUB`, `USD`, `KZT`, `CNY`?
   - Опциональное поле `converted`?
