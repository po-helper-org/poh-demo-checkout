# FNR-1: Пересчёт цены в международные валюты

**Статус:** исследование
**Источник:** Issue #11
**Дата создания:** 2026-08-19

---

## 1. Постановка задачи

### 1.1. Описание проблемы
Пользователь требует добавить в систему демонстраций возможность одновременного показа цены в базовой валюте и её пересчёта в три международные валюты: USD, KZT, CNY.

### 1.2. Контекст
- Текущая система работает только с одной валютой (рубли, подразумевается из кода)
- Отсутствует какой-либо функционал мультивалютности
- Нет механизма конвертации денежных сумм
- Сервис предназначен для демонстраций клиентам

### 1.3. Ожидаемый результат
При расчёте стоимости заказа система должна возвращать:
1. Основную валюту (текущее поведение)
2. Пересчитанную цену в USD (доллар США)
3. Пересчитанную цену в KZT (тенге)
4. Пересчитанную цену в CNY (юань)

### 2.2. Логика расчёта цены

**Модуль расчёта:** `src/pricing.mjs:591-643`

**Ключевые функции:**

1. **`subtotal(items)`** — `src/pricing.mjs:612-625`
   - Считает сумму позиций без доставки
   - Возвращает число (рубли)

2. **`deliveryFee(amount)`** — `src/pricing.mjs:631-633`
   - Определяет стоимость доставки
   - Возвращает число (рубли)

3. **`quote(items)`** — `src/pricing.mjs:639-643`
   - Основная функция расчёта
   - Возвращает объект: `{ goods, delivery, total }`
   - Все значения — числа в рублях

```javascript
export function quote(items) {
  const goods = subtotal(items);
  const delivery = deliveryFee(goods);
  return { goods, delivery, total: goods + delivery };
}
```

**Доказательство:** Функция `quote()` возвращает объект с тремя числовыми полями. Валюта нигде не указывается, подразумевается рублевая (судя по комментариям и константам в `src/pricing.mjs:596-601`).

### 2.3. Тестовое покрытие

**Тесты:** `tests/pricing.test.mjs:703-756`

Все тесты проверяют расчёт в одной валюте:

**Доказательство:** В тестах нет упоминания валют, конвертации или мультивалютности.
