function parseEnvNumber(name, defaultValue, min = 0) {

## Концепт 4: Креативный хак (Фабрика функций)

### Суть

Создание фабрики функций `createPricing(config)`, которая возвращает функции с замкнутыми параметрами. Позволяет создавать разные инстансы логики для разных сценариев.

### Изменяемые файлы

**`src/pricing.mjs`:**
```javascript
/**
 * Создаёт набор функций расчёта с заданными параметрами.
 * @param {{deliveryFee: number, freeDeliveryFrom: number}} config
 */
export function createPricing({ deliveryFee, freeDeliveryFrom }) {
  if (!Number.isFinite(deliveryFee) || deliveryFee < 0) {
    throw new Error('deliveryFee должен быть неотрицательным числом');
  }
  if (!Number.isFinite(freeDeliveryFrom) || freeDeliveryFrom < 0) {
    throw new Error('freeDeliveryFrom должен быть неотрицательным числом');
  }

  const deliveryFeeFn = (amount) =>
    amount >= freeDeliveryFrom ? 0 : deliveryFee;

  const remainingUntilFree = (amount) => {
    const remaining = freeDeliveryFrom - amount;
    return remaining > 0 ? remaining : 0;
  };

  const quote = (items) => {
    const goods = subtotal(items);
    const delivery = deliveryFeeFn(goods);
    return { goods, delivery, total: goods + delivery };
  };

  return { deliveryFee: deliveryFeeFn, remainingUntilFree, quote };
}

// Дефолтный инстанс для обратной совместимости
const defaultPricing = createPricing({
  deliveryFee: Number(process.env.DELIVERY_FEE || 300),
  freeDeliveryFrom: Number(process.env.FREE_DELIVERY_FROM || 3000),
});

export const deliveryFee = defaultPricing.deliveryFee;
export const remainingUntilFree = defaultPricing.remainingUntilFree;
export const quote = defaultPricing.quote;
```

### Плюсы
- ✅ Валидация параметров при создании
- ✅ Гибкость — можно создать разные инстансы
- ✅ Тестируемость — легко передавать моки
- ✅ Параметризация через окружение

### Минусы
- ⚠️ Увеличивает сложность кода
- ⚠️ Может быть избыточным для текущих нужд
- ⚠️ Требует рефакторинга тестов

### Усилия
**3-4 часа**

- 1.5 час — реализация фабрики
- 1 час — обновление тестов
- 30 мин — документация
- 30-60 мин — отладка

### Риски
- **Средний риск:** Новая концепция может быть непонятна другим разработчикам
- **Низкий риск поломки:** Сохраняется обратная совместимость

## Дебаты (Архитектор vs Адвокат Дьявола)

### Раунд 1: Защита Концепта 1 (Прагматичный)

**Архитектор:**

- **Следует существующему паттерну проекта** — доказательство: `src/server.mjs:8` использует `process.env.PORT || 8080`. Это естественный способ параметризации в проекте, не требующий новых зависимостей.

- **Дефолтные значения гарантируют обратную совместимость** — если переменные окружения не заданы, используются текущие значения (300/3000). Деплой без переменных окружения не сломает существующее поведение.

- **Минимальные изменения = низкий риск поломки** — зона воздействия точно определена в `task.md:85-92`: только `src/pricing.mjs` и `tests/pricing.test.mjs`.

- **Не требует новых зависимостей** — проект явно не использует внешние библиотеки для конфигурации. Вводить новую зависимость для двух параметров избыточно.

- **Легко масштабируется в будущее** — если потребуется больше параметров, можно эволюционировать в Концепт 2. Но для текущей задачи (2 параметра) это overengineering.

**Адвокат Дьявола:**

- **Отсутствие валидации значений** — при `Number(process.env.DELIVERY_FEE || 300)` если передать `"abc"`, получится `NaN`. Функция `deliveryFee()` вернёт `NaN >= FREE_DELIVERY_FROM ? 0 : DELIVERY_FEE` → `false` → вернёт `NaN` как плату за доставку. Это сломает клиентов.

- **Глобальность переменных окружения** — `process.env` глобален для всего процесса. Если в будущем потребуется разные инстансы с разными параметрами (мульти-тенантность), этот подход не масштабируется.

- **Отсутствие документации переменных** — нигде не видно, какие переменные окружения поддерживаются. Разработчик деплоя должен угадывать или читать код.

- **Хрупкость при изменении имён** — если завтра решим переименовать `FREE_DELIVERY_FROM` в `FREE_DELIVERY_THRESHOLD`, придётся менять во всех местах деплоя. Концепт 2 решает это через `.env.example`.

- **Проблема с тестированием** — тесты импортируют `DELIVERY_FEE` и `FREE_DELIVERY_FROM` напрямую (`tests/pricing.test.mjs:5-6`). После изменений эти импорты сломаются — константы больше не экспортируются.
